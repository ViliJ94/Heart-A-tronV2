PHASE 1: PIO ADC HANDLER (NEW MODULE)
================================================================================
File: Code/classes/pio_adc_handler.py (320 lines)

Created two new classes:

1. CircularBuffer
   - Non-blocking FIFO queue (256-entry circular buffer)
   - Methods: write(), read(), is_empty(), available(), clear()
   - Tracks overflow events for debugging

2. PIOADCHandler
   - Timer-based deterministic ADC sampling at 250 Hz (4ms interrupts)
   - Uses machine.Timer for precise hardware-controlled timing
   - Methods: start(), stop(), read_sample(), read_available(), get_stats()
   - Graceful fallback if ADC initialization fails
   - Debug stats: sample count, buffer depth, overflow events

WHY: RP2040 ADC cannot be directly PIO-triggered. Timer provides best
     practical precision without complex hybrid PIO/DMA code.

================================================================================
TECHNICAL DECISIONS
================================================================================

1. Timer-based instead of raw PIO
   - ADC cannot be directly PIO-triggered in RP2040
   - Timer more practical than hybrid PIO/DMA

2. 256-entry circular buffer
   - Absorbs up to ~50ms bursts (12-13 samples at 250 Hz)
   - Graceful overflow logging, no crashes

3. Local buffer in SensorManager
   - Isolates buffering logic from measurement engine
   - Filters and downstream processing completely unchanged

4. Dual sampling approach
   - PIO buffered sampling + timing-based fallback
   - Graceful degradation if PIO unavailable

5. Single-direction history scrolling
   - Simplified UX: down arrow only for navigation
   - Wrap-around instead of boundary stopping
